# Dayananda Sagar Campus Navigation System

An interactive web-based campus navigation system developed to help students and visitors find locations within Dayananda Sagar College of Engineering.

## 📌 Problem

General map applications may not provide detailed navigation for locations inside a college campus.

This project provides a simple campus-specific navigation interface where users can select a starting location and destination and receive route information.

## 🚀 Features

- Campus location selection
- Starting point and destination selection
- Route information
- Distance estimation
- Estimated travel time
- Campus location details
- Voice/audio navigation support
- Simple and user-friendly interface
- Responsive web design

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
